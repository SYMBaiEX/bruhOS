# Visual assets

Character artwork `bruh.webp` and favicon downloaded from https://bruhos.ai/ for
this bruhOS trace console, following the contributor's request to match the brand.
They are existing bruhOS brand artwork, not newly generated assets. No new license
for those brand assets is asserted by this contribution.

Outfit and Geist Mono font files are from Google Fonts; their SIL Open Font
Licenses are included alongside the fonts. The colors and typography were verified
against https://bruhos.ai/styles.css?v=17 on October 23, 2026.
